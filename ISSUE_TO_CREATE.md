# OctoAcme Project Management Documentation

Welcome to the OctoAcme Project Management documentation hub! This collection of documents defines how we run projects, coordinate teams, and deliver value to our customers.

## About OctoAcme's Project Management Process

OctoAcme follows a customer-first, iterative delivery approach built on these core principles:

- **Customer-first**: We prioritize customer value and usability in every decision
- **Iterative delivery**: We deliver small, testable increments for faster feedback
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Lead
- **Data-informed decisions**: We measure impact and iterate based on evidence
- **Psychological safety**: We encourage feedback and continuous learning

### Our Project Lifecycle

Projects at OctoAcme follow a structured lifecycle:
1. **Initiation**: Define problem statement, stakeholders, and high-level timeline
2. **Planning**: Determine scope, resources, milestones, and dependencies
3. **Execution**: Build, test, review, and iterate on deliverables
4. **Release**: Deploy, verify, and announce to stakeholders
5. **Close & Retrospective**: Capture learnings and identify next steps

### Key Roles
- **Project Manager (PM)**: Coordinates delivery, schedules, risk, and communications
- **Product Manager (PdM)**: Defines outcomes, prioritizes backlog, measures success
- **Developers**: Implement features and collaborate on design
- **QA/Testing**: Validate quality and acceptance criteria
- **Stakeholders**: Provide inputs and approvals
